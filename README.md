# Ganbarou Pomodoro 🍅  

A customizable pomodoro timer web app to help you get in the zone!

## Features
- Switch between 25/5 and 50/10 modes
- Long break after every 4 rounds
- Upload your own background
- Choose your own round-end jingle

## Get Started ｜　始まる
Website link: https://ganbarou-pomodoro.netlify.app/

HTML, CSS, and JavaScript

# 頑張ろう・ポモドーロ　🍅
カスタマイズできるポモドーロウェブサイトアプリであります。

## 機能
- 25/5 と　50/10 タイマーモードセットできます。
- ４ラウンドが終わったら、長い休憩があります。
- 自分のバックグラウンド写真をアップロードすることができます
- 自分のラウンドエンド音をアップロードしたり、選んだりすることができます。

## 始め方
